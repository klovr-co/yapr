# Twitch Copy Formats & Constraints

Character limits, format rules, and platform requirements for each copy type.

## Stream Title
- **Limit**: 140 characters (Twitch hard limit); aim for 60-80 chars for full visibility in browse
- **Format**: Plain text, no markdown
- **Tips**: Front-load the hook — first 40 chars are visible in thumbnails. Avoid clickbait that doesn't deliver.
- **Emojis**: Optional, 1-2 max, only if authentic to streamer's brand

## Channel Description (About section)
- **Limit**: 300 characters
- **Format**: Plain text
- **Structure**: [Who you are] + [What you stream] + [Why watch you specifically]
- **Tips**: One sentence max per point. No bullet lists — prose reads better here.

## Panels
Each panel is its own image + optional text block below it.

| Panel | Text Limit | Purpose |
|-------|-----------|---------|
| About Me | ~500 chars | Personality, background, why you stream |
| Schedule | ~300 chars | Days/times + timezone |
| Rules | ~400 chars | Community guidelines, tone |
| Donate/Support | ~300 chars | CTA + context for why |
| Social Links | ~200 chars | Where to find you |
| Commands | ~400 chars | Bot commands list |

- **Format**: Markdown supported in panel text
- **Tips**: Use short lines. Panels are read quickly. Lead with the most important info.

## Raid Message
- **Limit**: 255 characters (Twitch chat message limit)
- **Format**: Plain text, emojis common and encouraged
- **Tips**: Written in second person ("We're bringing X energy"). Should feel like a hype crowd arriving, not a corporate announcement. Include the target channel name as `{channel}` placeholder when templating.

## Sub / Bit Celebration (Chat Alert Text)
- **Limit**: ~500 characters
- **Format**: Plain text or simple formatting
- **Types**: New sub, resub (with months), gift sub, bits cheer
- **Tips**: Match the streamer's energy. Hype streamers want ALL CAPS energy; chill streamers want warm, personal responses. Personalize with `{username}` and `{months}` placeholders.

## Clip Title
- **Limit**: 100 characters
- **Format**: Plain text
- **Tips**: Titles travel off-platform (Twitter, TikTok, Discord). Write for someone who hasn't seen the clip — create curiosity. Strong format: [What happened] + [why it's surprising/funny/impressive]

## Social Posts

### Twitter/X
- **Limit**: 280 characters (25 for URL)
- **Effective limit**: ~240 chars for copy
- **Format**: Plain text, hashtags optional (1-2 max, at end)
- **Going Live**: Lead with the "what's happening today" hook, not just "I'm live"

### TikTok Caption
- **Limit**: 2,200 characters; only first 100 visible before "more"
- **Effective limit**: Hook in first 80 chars
- **Format**: Plain text, 3-5 hashtags standard

### Instagram Caption
- **Limit**: 2,200 characters; first 125 visible
- **Format**: Line breaks matter, hashtags at end or in comments

### YouTube Community Post
- **Limit**: 500 characters recommended
- **Format**: Markdown not supported

## Overlay Text (Stream Alerts & Intermission)
- **Limit**: Very short — 5-10 words for alerts, 1-2 sentences for intermission screens
- **Format**: Must be readable at a glance while watching gameplay
- **Types**: Follow alert, sub alert, raid alert, BRB screen, starting soon screen, just chatting screen
- **Tips**: Match energy to stream mood. "BRB, don't leave me" vs. "Taking a short break, be right back" — totally different vibes.
